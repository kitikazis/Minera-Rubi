# PROMPT PROFESIONAL - PÁGINA WEB EL RUBÍ MINERÍA

## BRIEF CREATIVO

Diseña una página web corporativa para una empresa minera llamada "El Rubí" especializada en extracción y procesamiento de gemas minerales de alta calidad. La empresa busca proyectar profesionalismo, innovación y compromiso con la sostenibilidad ambiental.

## REGLA DE ORO

Tiene que ser en php puro usando la estructura MVC

## ELEMENTOS GRÁFICOS Y EFECTOS

### Animaciones

- Hero: Fade-in de elementos al load
- Scroll: Parallax en hero section (video/imagen)
- Stats: Números animan al scroll (contador)
- Cards: Fade-in con delay staggered
- Botones: Glow dorado al hover, transición 300ms
- Timeline: Items aparecen en secuencia
- Iconografía: Rotación suave al hover

### Interactividad

- Hover global: Elevación de cards con sombra
- Enlaces: Subrayado dorado al hover
- Botones: Brillo/glow effect, cambio de escala 1.05
- Formulario: Focus effects con borde dorado
- Navegación: Indicador activo dorado

### Separadores / Divisores

- Líneas doradas: 2px ancho, máximo 200px
- Decorativas entre secciones
- Diagonal dividers con SVG (opcional avanzado)
- Espaçiado: 60px arriba y abajo (desktop)

### Tipografía de Acentos

- Primeras palabras en oraciones: #EBAF00 (subtil, solo destaca)
- Números grandes: #EBAF00 siempre
- CTAs: Mayúsculas con tracking 2px

## RESPONSIVE DESIGN

### Breakpoints

- Desktop: 1440px+
- Tablet: 768px - 1439px
- Mobile: 375px - 767px

### Mobile-First Approach

- Navegación: Hamburger menu (3 líneas doradas)
- Hero: Altura 70vh, fuentes más pequeñas
- Grids: 1 columna (productos), 1 columna (valores)
- Tipografía: Escalada según viewport
- Padding/Margin: Reducido 50% en mobile
- Videos: Poster con imagen en lugar de autoreproducción
- Botones: Full width en mobile

## CÓDIGO Y ARQUITECTURA

**Framework:** PHP MVC Vanilla (sin Laravel/Symfony)

**Estructura Base:**

- index.php (router)
- controllers/ (lógica de negocio)
- views/ (plantillas HTML)
- assets/ (CSS, JS, imágenes)
- config/ (configuración global)

**Base de Datos (opcional):**

- Tabla: minerales (id, nombre, dureza, aplicaciones)
- Tabla: procesos (id, orden, titulo, descripcion)
- Tabla: contactos (id, nombre, email, asunto, mensaje, fecha)

**Librerías Frontend:**

- Bootstrap 5 (responsive grid)
- GSAP (animaciones avanzadas)
- AOS (Animate On Scroll)
- Google Maps API (ubicación)
- Lightbox (galería)

**SEO Base:**

- Meta tags por página
- Schema markup (LocalBusiness, Organization)
- Sitemap.xml
- Robots.txt
- OpenGraph tags
